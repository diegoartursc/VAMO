# 📋 Logs de Prompts — Prova de Autoria Humana

Esta pasta contém registros históricos de todos os **prompts humanos** feitos durante o desenvolvimento do projeto VAMO.

## Objetivo

Documentar e comprovar que **todas as decisões, direções e solicitações** do projeto foram feitas por um ser humano real. Cada entrada é um prompt escrito manualmente pelo desenvolvedor/idealizador do projeto, provando a autoria e a intencionalidade humana por trás de cada funcionalidade.

## Estrutura

Os logs são organizados por semana no formato `YYYY-WXX.md` (ex: `2026-W07.md`).

Cada entrada contém:
- 📅 **Data e hora** exata do prompt
- 💬 **Prompt humano** — a solicitação original feita pelo desenvolvedor
- 🏷️ **Contexto** — área do projeto sendo trabalhada

## Como ler

Cada log semanal mostra a sequência cronológica de decisões humanas que guiaram o desenvolvimento. Isso demonstra:
- O **raciocínio humano** por trás de cada feature
- A **evolução das ideias** ao longo do tempo
- Que o projeto foi **dirigido por uma pessoa real** com visão e objetivos claros
